# История батареи для Noctalia

График заряда по **ПКМ на штатном виджете батареи**. Левый клик сохраняет обычное действие Noctalia. Плагин не добавляет ещё один виджет в бар. Панель открывается в плавающем режиме, отдельно от бара.

Поддерживается Noctalia 5.4.1 (plugin API 42 и выше). Нужны Python 3, модуль `cairo` для Python, `busctl` с поддержкой JSON и работающий UPower. На этой машине зависимости уже установлены. Для Arch-подобных систем пакеты: `python`, `python-cairo`, `systemd`, `upower`.

## Использование

- ПКМ на батарее открывает и закрывает панель. Escape или клик снаружи закрывает её.
- При открытии отображаются последние 24 часа; кнопки выбирают 1, 6, 12 или 24 часа.
- Стрелки сдвигают окно на выбранную длительность. «Сейчас» возвращает к текущему времени.
- Кнопка календаря открывает список дат за последние 30 дней. Выбери дату и нажми «Показать день».
- Слева фиксированная шкала 0–100%, снизу местное время. Для интервала через полночь указаны даты.
- Наведение показывает точку и строку с временем, зарядом, состоянием и скоростью разряда за предыдущие 15 минут. Скорость выражена в процентных пунктах в час.
- Пунктир соединяет измерения с промежутком более трёх минут. Он не означает, что промежуточный заряд известен. Скорость через такие промежутки не рассчитывается.

## Установка из этой папки

Исходники подключаются через ссылку, поэтому изменения `.luau` подхватываются Noctalia автоматически.

```bash
mkdir -p ~/.local/share/noctalia/plugins
ln -s /home/geralttop/my_folder/projects/2026/battery-plugin ~/.local/share/noctalia/plugins/battery-history
noctalia msg config-reload
noctalia msg plugins enable geralttop/battery-history
```

После включения дождись появления плагина в `noctalia msg plugins list`. Первый экспорт выполняется в фоне. Затем назначь действие:

```bash
noctalia msg config-set widget.battery.actions.right '"panel-toggle geralttop/battery-history:history"'
```

Это назначение записывается через штатный API настроек Noctalia и переживает перезапуск. Если штатный виджет называется иначе, подставь его имя вместо `battery`. Другие действия мыши не изменяются.

Открыть панель отдельно:

```bash
noctalia msg panel-toggle geralttop/battery-history:history
```

## Хранение и работа в фоне

Сервис плагина снимает измерение раз в минуту, даже когда панель закрыта. Он прекращает работу вместе с Noctalia. Системная история UPower импортируется при первом запуске и затем каждые шесть часов; её полнота зависит от UPower.

История хранится в SQLite, транзакционно, отдельно для каждой физической батареи; записи старше 30 дней удаляются. Данные не отправляются в сеть. В обычной конфигурации каталог:

```text
~/.local/state/noctalia/plugins/data/geralttop/battery-history/
```

Изменения `XDG_STATE_HOME` и `NOCTALIA_STATE_HOME` учитывает сама Noctalia через `pluginDataDir()`. Не сохраняй историю в папке исходников плагина.

График рисует вспомогательный процесс Python/Cairo через `ui.pixelStream`. Он существует только при открытой панели, не устанавливает системную службу и завершает работу при закрытии панели. При отсутствии UPower ранее накопленная история остаётся доступной.

## Откат

До установки у штатной батареи на этой машине не было отдельной привязки ПКМ. Вернуть это поведение можно, удалив `right` из `[widget.battery.actions]` в настройках Noctalia; временно отключить действие — командой:

```bash
noctalia msg config-set widget.battery.actions.right '"none"'
noctalia msg plugins disable geralttop/battery-history
```

История при отключении не удаляется. Ссылка `~/.local/share/noctalia/plugins/battery-history` может быть удалена отдельно без удаления проекта.

## Проверка

```bash
noctalia plugins lint .
python3 -m unittest discover -s tests -v
lua tests/test_panel.lua
```

Проверяются импорт и ошибки UPower, нулевой заряд, объединение измерений, срок хранения, разделение батарей, расчёт скорости и пропуски, работа Unix-сокета и shared-memory протокола, навигация и жизненный цикл панели.

Дизайн панели описан в [PLAN.md](PLAN.md); изображения в `mockups/` — предыдущие исследования внешнего вида отдельного виджета, который в итоговом решении не используется.

При подключении проверены фактические ПКМ по штатной батарее, переключение периода, выбор дня, наведение и завершение процесса графика при закрытии панели. Импортировано 583 системных измерения; новые точки продолжают накапливаться раз в минуту. Редкая системная история в основном отображается пунктиром, потому что UPower сохраняет изменения заряда с большими промежутками. По мере накопления минутных измерений плагина появляется сплошная линия.
